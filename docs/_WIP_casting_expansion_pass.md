## 0. 목적

**핵심 제약(사용자 결정):**

**⚡ 어텐션 이코노미 (2026-07-12 보강 — 딜 최소주의):** 플레이어 인지예산은 **Tank(어그로)·Healer(힐싸이클)·Movement·적 대응**이 지배(3서브×4클래스=12버튼 포화). 딜은 **잔여 주의로 최소 조작**하되 "딜 기분"은 남긴다.

### 시전 티어 밴드 (**레퍼런스** — 2026-08-07 실물 기준 재작성, DRIFT-120)

> **A/B/C 3밴드를 폐기하고 실제 분포에서 다시 유도했다.** 종전 표(A 0~0.4 / B 3~5 / C 8~15)는 **실물을 설명하지 못했다** — ① **C(8~15s)에 해당 스킬이 0종**(마지막 주민 AB-066이 5.5s로 내려왔다) ② 실재하는 **1.0~1.2s**(보호막·돌진·속박 6종)와 **2.0~2.5s**(독장판·광역도발 2종)가 **어느 밴드에도 없었다** ③ 채널링(지속 3.5~4.2s)은 `cast_s`가 아닌데 밴드가 다루지 않았다. 밴드는 척도인데 척도가 실물을 못 재면 쓸모가 없다.
> 이름도 A/B/C → **역할 이름**으로 바꿨다. `castTier` 필드는 아군 측 **죽은 스키마**라 글자에 코드 의미가 없고, "B 밴드"보다 "**셋업** 밴드"가 판정 때 훨씬 잘 읽힌다.

| 밴드 | 길이 | 역할 | 실례 |
|---|---|---|---|
| **즉발** | 0s | **반응·유지** — 맞고 나서 켜는 것, 켜 두는 것. 도발·DR·반격·방벽·정화·은신·시야·버프 | 28종(절반 이상) |
| **즉응** | 0.8~1.5s | **급박한 대응·진입** — 지금 안 하면 늦는 것 | 보호막 3종(067/065/075) · 돌진 013 · 속박 102 |
| **셋업** | 2.0~2.5s | **판을 까는 것** — 뒤에 올 무언가를 위한 준비 | 독장판 010 · 광역 도발 035 |

> **6초 초과 밴드는 두지 않는다(2026-08-07).** 종전 C(8~15s)의 자리는 **채널이 가져갔다.** 긴 시전은 "기다렸다가 한 번 터진다"라 중간에 할 게 없지만, 채널은 **매 틱 효과가 나오고 언제든 끊긴다** — 같은 길이를 쓰면서 상호작용이 있다. 10초짜리 캐스트가 실패한 이유도 같다(AB-066: 전투 중 10초 무피격 창이 없어 완주 자체가 불가능했다 → 5.5s, DRIFT-119).

> **⚠️ 밴드 = 레퍼런스, 강제 아님 (2026-07-28 사용자 확정, 유지).** *"이 길이면 대충 이런 역할"* 을 잡아 주는
> **참조 척도**이지 각 스킬을 밴드 하나에 **맞춰 넣어야 하는 규격이 아니다.** 스킬이 요구하는 길이가
> 밴드 사이에 떨어지면 **그 값 그대로 둔다** — 밴드에 맞추려고 스킬을 비트는 순간 척도가 목적이 된다.

### 2.0 검토 순서 (2-Phase — 2026-07-19 축 전환)
**검토 축을 ENC→스킬로 전환.** 기존 ENC 순회(§5.3) 대신 **스킬 전수(§5 표) 우선**.
- **Phase A — 스킬 전수 핑퐁(§5 표 순회):** 각 스킬을 표 순서로 §2.1의 4축(효과·방향·시전모드·바인딩)을 **1차 확정** + **통폐합 판단**(겹치는 효과 통합/차별화). 데이터 수정 → DRIFT 로깅 → 표 `[x]`. **밸런싱(딜/쿨 상대값)은 제외**(§0 스킵). Phase A가 확정하는 건 **밴드(시전모드)**까지.
- **Phase B — ENC 실전 밸런싱(§5.3 진행표):** ENC별 딜/쿨 상대값 밸런싱 + **맥락 재확인**. 판정-1회(첫 등장 ENC).
> **관계: Phase A = 잠정 / Phase B = 확정.** A의 시전밴드·통폐합이 B 실전에서 안 맞으면 **뒤집는다**(선례: HARD-001에서 AB-007 "A유지" 가설이 실전 체감으로 뒤집힘).

### 2.5 결속 링크 제안 (축4 보강 — Shared/Ally-only 전용)

> **⚠️ 2026-07-19 개정(DRIFT-087):** 아래 절차는 **whitelist 전제로 쓰였으나 그 전제가 폐기됐다.** 이제 정체성을 착용하면 장착한 **모든 서브**가 기본 델타(GENERIC)를 받는다 — 스킬별 "어느 정체성에 등록할까" 제안은 **더 이상 필요 없다.** 남은 축4 판정은 두 가지뿐: ① 이 서브가 **훅을 가졌나**(명중/치유 — 없으면 generic이어도 무효과, 존·블링크 사례) ② **변주가 필요한가**(초월/혈풍 `variant`, 슬롯 변주). 아래 클래스별 정체성 참조표는 그 판정용으로 유지.

Shared 서브(적도 드롭) 또는 Ally-only 서브는, 장착 가능한 **각 클래스**마다 이미 확립된 **2개 정체성**(`binding_overlays.gd` SIGNATURE)이 있다. 스킬별 판정 시 축4(바인딩)에서 다음을 함께 제안·기록한다:

1. `equip_classes`로 장착 가능 클래스를 확인.
2. 그 클래스(들)의 두 정체성 각각에 대해 "이 서브가 그 규약(delta)에 자연스럽게 들어맞는가"를 판단.
3. delta가 **generic**(코드 변경 없이 `OVERLAYS`에 항목만 추가하면 동작)인지, **kind별 분기가 필요한 special-case**(`overdrive_charge`의 화상/견인/빙결처럼 `ability_dispatch.gd`에 새 코드가 있어야 함)인지 구분.
4. 이 절은 **제안 기록만** — 실제 `OVERLAYS` 등록이나 신규 kind 분기 코드는 스킬별 컨펌 후 별도 승인(§8 Stop-line).

## 5. 전수 스킬 표 (Phase A — **유사도 × 주력 클러스터**)

> 캐스터/탱 서브 **50종 전수**(Nuker/DPS/Healer/Tank equip; Identity IDA-### 제외). **완료 41 / 미완료 9.**
> **2026-07-28 T1 완결(DRIFT-101):** AB-071·049·104 폐기(60→57종) — 자세한 건 T1 헤더.
> **2026-07-28 클러스터 정의 개정:** 클러스터 = **효과(툴팁)·kind 유사도 × 주력 클래스**. **주력이 다르면 같은 툴팁이라도 같은 클러스터로 보지 않는다** — 클래스별 방향성을 따로 고정하면(예: Tank = 제어 / DPS = 피해) 문구가 겹쳐도 역할이 갈리기 때문. **통폐합 판정은 클러스터 내부에서만** 한다. (구 §5.0 클러스터×주력 교차표는 **폐지** — 이 정의에 흡수.)
> - **주력** = `equip_classes` − `sub_bands`(json `_note`: 미기재 = main/B0 full, 기재 = sub/B1~B3). **주력이 같다 = 같은 Q/E/R 3슬롯에서 실제 경합한다.**
> - **클러스터 ID** = 클래스 머리글자 + 번호(**T**ank · **D**PS · **N**uker · **H**ealer). 순서 = 클래스 → 중복 압력. **클러스터 내부는 ✅완료 먼저**(= 그 계열의 확정 선례) → 미완료.
> - **차이축** = 그 클러스터 안에서 이 스킬만 다른 값(`skillbooks.json` cast 실값). 공통값은 클러스터 헤더로 뺐다.
> - **조준** = `targeted:true`(지면/적 조준) · **자기중심** = 조준 없음(시전자 반경) · **자동** = 대상 자동 선정. 툴팁이 "대상 지역"이어도 실제 자기중심이면 표기했다.
> - **밴드** = 목표 시전밴드(A 0~0.4 / B 3~5 / C 8~15) — **레퍼런스일 뿐 강제 아님**(§1). 밴드 사이 값이면 **실제 `cast_s`를 그대로** 적는다. 완료는 `DONE`(상세 = [DONE §4](_WIP_casting_expansion_pass_DONE.md)).
> - **관련 ENC** = encounters 전수 매핑(Phase B 맥락). `[uni]` = 적↔아군 통합 · **Ally** = 적 미사용.
> - ⚠️ **cast·cd·dmg = 현황 참조**(§0 밸런싱 스킵) — Phase A는 **밴드(시전모드) + 통폐합**만 확정.

### 5.1.9 ⏳ 보류 — **정체성(identity) 축 미고려** (2026-08-06, 사용자 확정)
